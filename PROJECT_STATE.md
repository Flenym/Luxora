## Текущая архитектура

- **Backend:** Node 22 Fastify API (`services/api`), SQLite WAL + строгие миграции (последняя `043_device_link_step_up`), V2 realtime outbox, capability negotiation, 12-collection reconciliation snapshot. Шифрование at-rest для секретов; сервер технически может читать сообщения — **это не E2EE** (честно зафиксировано). CORS теперь допускает все браузерные mutation-методы (`GET/HEAD/POST/PUT/PATCH/DELETE/OPTIONS`) по exact-allowlist и отдаёт только безопасные exposed-заголовки (`ETag`, `Content-Range`, `Accept-Ranges`, `Content-Disposition`, `Retry-After`, `X-Content-Type-Options`); есть preflight regression test (`services/api/src/cors-preflight.integration.test.ts`).
- **Protocol:** `@luxora/protocol` — строгие zod-контракты. Realtime v2 аддитивен: durable события мессенджинга, IA-1/membership/preferences/folders/drafts/sync-invalidated и `call.state.changed` (только `callId/chatId/state/revision/occurredAt`, без media/SDP/ICE/TURN/grant-материала).
- **Calls:** серверный call control (миграции `038_call_control_records`, `039_call_room_index`): create/get/cancel/hangup, group invite, ring/accept/decline, join-grant (LiveKit HS256 JWT 120 c + coturn REST 300 c), подписанный LiveKit-webhook, membership-reconcile и stale-reconnecting sweeper. `call.state.changed` пишется в одной транзакции со снапшотом и outbox; клиент перечитывает звонок через REST. `GET /v1/capabilities` отдаёт `features.calls:true` **только** когда настроены все пять `CALLS_*` переменных; иначе `calls:false`, а join-grant отдаёт `503`.
- **Медиаплан:** `docker-compose.calls.yml` поднимает LiveKit SFU, coturn и Caddy TLS (`wss://localhost:7443`); `start.bat` → `scripts/start-all.ps1` генерирует `data/media.env`, поднимает стек, доверяет локальному CA, стартует API на 2222 и публикует его через CloudPub CLI. Локальный harness, не production-топология.
- **Web:** публичный продуктовый сайт завершён (14 маршрутов, 22 docs-страницы RU/EN, SEO/JSON-LD/canonical/OG/robots/sitemap, а11y, lazy 3D hero) и веб-клиент мессенджера по `/app` реализован: React, `src/app/core` (REST-клиент с access-токеном в памяти и refresh в `sessionStorage`, realtime `/v2`, чистые store-хелперы, call-media адаптеры) + `src/app/ui` (sidebar/conversation/composer/attachments/calls overlay/dialogs); dev/preview proxy `/v1`, `/v2`, `/health` → `127.0.0.1:2222`. Клиент — developer preview, не выпущенный продукт.
- **Клиенты:** iPhone — SwiftUI + Keychain + realtime + серверные stores; calls preview: `CallsStore` + `CallBanner` + `CallMediaSession` (LiveKit SDK, голос только при сконфигурированном медиаплане); поверх этого добавлена call surface: вкладка истории звонков, per-chat лог, in-call overlay с честным mute и call-back (код в `4918cfa`, ждёт Apple CI). Community management UI (invite links/join requests/ownership transfer/join-by-link) тоже в `4918cfa`, ждёт Apple CI. Electron — закалённый shell, грузящий `apps/web/dist`. Android — demo-only.
