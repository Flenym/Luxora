## ✨ Что такое Luxora?

**Luxora** — премиальный мессенджер с протоколом в основе, который создаётся открыто: спокойный, светящийся, точный.

Большинство мессенджеров просят верить расплывчатым словам: *«защищено»*, *«доставлено»*, *«в сети»*. Luxora идёт противоположным путём:

- 🔍 **Честная приватность.** Режим доверия виден до того, как вы что-то написали. Никаких замочков, которые ничего не значат.
- 📬 **Честная доставка.** *Отправлено*, *Доставлено* и *Прочитано* появляются только тогда, когда протокол может это доказать, — а не по таймеру.
- 🧩 **Один протокол — нативные клиенты.** iPhone, Android, Web и Desktop разделяют одинаковую семантику сообщений, identity и приватности — с полностью нативным UX на каждой платформе.
- 🛡 **Безопасность как гейт, а не слоган.** Сквозное шифрование и звонки появятся только после независимого аудита и сквозных доказательств — а не как маркетинговое заявление.

> Текущее состояние: **Beta-0.1 · Cloud preview**. Соединения защищены в транзите, тела сообщений могут шифроваться на диске — но сервер обрабатывает открытый текст. **Эта сборка не имеет сквозного шифрования. Не используйте её для чувствительных данных.**

## 💜 Видение

<div align="center">

> *«Премиальность никогда не допускает вводящего в заблуждение символа безопасности».*

</div>

Пять принципов Luxora:

| # | Принцип | Что это значит |
|---|---------|----------------|
| 01 | **Сначала правда, потом глянец** | Клиент не вправе выдумывать receipt, security-статус или возможность, которую не может доказать протокол. |
| 02 | **Спокойствие по дизайну** | Глубокие нейтральные поверхности, одна сдержанная фиолетовая лента для фокуса, анимация, объясняющая непрерывность, — никакого шума. |
| 03 | **Приватность, которую можно прочитать** | Сегодня — `Cloud preview`. `Private` (аудированный E2EE) и `Moderated` — только после прохождения гейтов. Ярлык всегда говорит правду. |
| 04 | **Сначала сервер, потом клиенты** | Одна завершённая серверная платформа → одно завершённое iPhone-приложение → все остальные платформы. Никакого расхождения семантики между семью клиентами. |
| 05 | **Доказательства вместо обещаний** | Каждое заявление подкреплено тестами, гейтами и ревью. Функции roadmap никогда не показываются как работающие без метки `prototype` / `coming later`. |

Цель: мессенджер как тихое светящееся пространство — где каждый пиксель, каждое состояние и каждое слово о приватности заслужены.

## 🎛 Возможности

### 🟢 Доступно — Beta-0.1

Реальные, протестированные фундаменты (не мокапы):

|  | Возможность | Описание |
|---|---|---|
| 📜 | **Общий протокол** | Строгие Zod-контракты HTTP + realtime: identity, чаты, сообщения, receipts, ошибки, лимиты |
| ⚙️ | **Ядро backend** | Node.js 22 + Fastify, SQLite WAL с транзакционными миграциями, health/readiness, OpenAPI, метрики Prometheus |
| 🔑 | **Аутентификация и сессии** | Argon2id-вход, короткоживущий JWT, hash-only ротация refresh-токенов, сессии на устройство с отзывом |
| 📱 | **Phone-онбординг** | Строгий E.164 + 6-значный OTP, ветки регистрации / входа, подсказки username, recovery и привязка legacy-аккаунтов |
| 💬 | **Сообщения** | Лички, группы, каналы · текст · ответы · пересылка · история правок · пины · реакции · прочтения |
| 🗂 | **Организация** | Папки чатов, архив и мьют, синхронизированные черновики, отложенная отправка, топики, invite-ссылки, очереди заявок на вступление |
| 🛡 | **Безопасность общения** | Приватный поиск, запросы на переписку, направленные блокировки, репорты с доказательствами |
| ⚡ | **Realtime** | Аутентифицированный WebSocket V2 с курсором и replay, heartbeat, backpressure, typing и presence |
| 📦 | **Медиа-стейджинг** | Возобновляемая зашифрованная загрузка, авторизованное хранилище, byte-range скачивание, квоты и очистка |
| 🐳 | **Закалённый рантайм** | Distroless non-root контейнер, digest-пины образов, чистый Trivy, локальный стек на loopback |

### 🟡 В разработке

Активная работа — уже видна в коде, но ещё не продукт:

|  | Направление | Куда движемся |
|---|---|---|
| 👑 | Передача владения | Двухшаговая церемония с revision-защитой |
| 🎙 | Голосовые сообщения | Сквозной QA: запись → загрузка → воспроизведение → транскрипт по согласию |
| 🖼 | Обработка медиа | Серверные thumbnails, waveform / длительность, quarantine- и transcode-пайплайн |
| 🔎 | Завершение поиска | Глобальная пагинация, политика контактов, permission-first гарантии |

### 🔵 Запланировано

Явные фазы roadmap — это **не** работающие функции:

|  | Направление | Гейт |
|---|---|---|
| 📞 | Платформа звонков | Версионированный signaling, SFU / TURN, screen share — только после security review и лабораторных доказательств |
| 🔐 | Private E2EE | Аудированная криптография 1:1 и групп, key transparency, verification UX, независимый аудит |
| 🔔 | Настоящие push | Credentials APNs / FCM / Web Push, минимизированные payloads, измеренная доставка |
| 📲 | Passkeys для всех | Публичные signup / sign-in / management UX после гейтов abuse, recovery и интеропа |
| 🌍 | Production-платформа | Production-БД, масштабирование, бэкапы и DR, мониторинг, внешний pentest |

> **Правило правды:** всё из 🟡 и 🔵 никогда не показывается в продукте как уже готовое.

## 🖥 Платформы

Один протокол — нативный опыт везде. Строгий порядок: **сервер → iPhone → всё остальное**.

| Платформа | Технологии | Статус |
|---|---|---|
| 🌐 Сервер / API | Node.js 22 · Fastify · SQLite WAL | 🟢 Рабочий фундамент — активный фокус |
| 📱 iPhone | Swift 6 · SwiftUI · Keychain | 🟡 Тонкий интеграционный harness, живые доказательства контрактов |
| 📲 iPad | Общий Swift-фундамент | ⚪ Заморожен до стабильных сервера + iPhone |
| 💻 macOS | SwiftUI probe | ⚪ Заморожен — portability probe |
| 🤖 Android | Kotlin · Jetpack Compose | ⚪ Фундамент, не подключён к API |
| 🌍 Web | React + Vite | ⚪ Лендинг + локальный прототип, не сетевой клиент |
| 🪟💻 Windows / Linux | Закалённый Electron shell | ⚪ Packaging probe, без интеграции сообщений |

Детали: [CLIENTS.md](CLIENTS.md) · [MOBILE.md](MOBILE.md) · [WEB.md](WEB.md) · [DESKTOP.md](DESKTOP.md)

## 🗺 Roadmap

Без дат — фазы это направления работы с выходными гейтами, а не обещания.

### 🟢 Сейчас — завершить серверную платформу

Упрочнение текстового слайса · identity / устройства / доступ · полный домен чатов и сообществ · обработка медиа · завершение поиска / push / realtime · аудированные подсистемы звонков и E2EE · production-операции.

### 🔵 Далее — завершить iPhone

Все запланированные сценарии на стабильных серверных возможностях: онбординг, чаты, медиа, поиск, звонки, приватность — плюс offline-first хранилище, доступность, производительность и гейты App Store. Никаких demo-заглушек на рабочих поверхностях.

### 🟣 Будущее — остальные клиенты и публичный сайт

iPad → macOS → Android → Web → Windows / Linux → публичный сайт. Каждый перенимает доказанные контракты и проходит собственные truth-гейты.

```
1. COMPLETE SERVER PLATFORM
   ↳ thin iPhone harness verifies contracts only
2. COMPLETE iPHONE PRODUCT
3. UNFREEZE iPAD / macOS / ANDROID / WEB / WINDOWS / LINUX / PUBLIC SITE
```

Полный разбор: [ROADMAP.md](ROADMAP.md) · очередь работ: [TODO.md](TODO.md) · планка релиза: [docs/specs/RELEASE_QUALITY_GATES.md](docs/specs/RELEASE_QUALITY_GATES.md)

## 🔮 Будущее

Когда гейты будут пройдены, Luxora станет:

- 🔐 **Private-пространства** — проверяемые сквозно зашифрованные диалоги с верификацией ключей и transparency, где сервер видит лишь непрозрачные конверты.
- 👥 **Moderated-пространства** — сообщества с ролями, audit log, slow mode и апелляциями — с явным disclosure до вступления: что и зачем обрабатывается.
- 📞 **Звонки, заслужившие доверие** — голос и видео 1:1 и в группах с проверяемым состоянием шифрования, честной адаптацией к сети и без фейкового бейджа «защищено».
- 🔎 **Поиск без утечек** — permission-first поиск везде; Private-контент индексируется только локально, никогда — серверным открытым текстом.
- 📦 **Достоинство данных** — экспорт, жизненный цикл retention и удаление аккаунта, которые реально распространяются — включая бэкапы.

Ничего из этого не заявлено как готовое. У каждой строки — гейт, у каждого гейта — доказательства.

## 🤝 Сообщество и contribution

Luxora открыто разрабатывает **Flenym** — и вдумчивый вклад со стороны приветствуется.

- 💡 **Идеи** — откройте [issue](https://github.com/Flenym/Luxora/issues): пользовательский исход и фаза, к которой идея относится.
- 🐞 **Баг-репорты** — только синтетические данные: сборка / коммит, шаги, ожидаемое vs фактическое.
- ✨ **Предложения фич** — сначала сверьтесь с [ROADMAP.md](ROADMAP.md); замороженные клиенты не принимают новую семантику досрочно.
- 🔀 **Pull requests** — маленькие, сфокусированные, с тестами; изменения auth / crypto / миграций требуют независимого ревью.
- 🔒 **Репорты безопасности** — никогда не публикуйте эксплойты; см. [SECURITY.md](SECURITY.md#11-vulnerability-reporting).

Полный контракт: [CONTRIBUTING.md](CONTRIBUTING.md). Будьте доброжелательны, точны и честны о том, что готово.
