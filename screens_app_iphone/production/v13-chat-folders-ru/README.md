# Luxora Beta-0.1 — папки чатов и сообщества (iPhone)

Семь кадров сняты непосредственно с `LuxoraMobile` в iPhone 17 Pro Simulator
(iOS 26.5), без ретуши, склейки и дорисовки. Каждый PNG — полный кадр
`1206 × 2622`, экспортированный из сохранённого XCTest attachment.

Это воспроизводимый **DEBUG-only server-shaped сценарий** с синтетическими
данными, а не доказательство живого backend-сеанса. Release-сборка этот fixture
не содержит. При создании кадра архива тест действительно провёл по строке
«Избранное», нажал «В архив» и дождался подтверждённой проекции через тот же
production-путь `ApplicationSession.updateChatPreferences`; чат не был заранее
помечен архивным ради картинки.

Тест использует отдельные свежие процессы приложения для устойчивого evidence:
первый запуск снимает «Все» и затем реальный архив (18 → 17 + 1); второй
запуск снова начинает с исходных 18 чатов, выбирает «Команду» и проходит к
настройкам/редактору, после чего открывает сообщества. Поэтому счётчик «Все» на
кадре «Команда» снова равен 18 — это не откат архивной команды, а новый
детерминированный fixture-сеанс.

## Кадры

1. `01-all-chats.png` — системная папка «Все», 18 чатов.
2. `02-archive.png` — подтверждённый результат реального swipe-действия: 17 в
   «Все», 1 в «Архив».
3. `03-team-folder.png` — выбранная сервероподобная папка «Команда», включая
   явное включение muted-канала.
4. `04-folder-settings.png` — полный список папок, выбранная «Команда» и вход в
   создание папки.
5. `05-folder-editor.png` — русский редактор: название, типы, условия и
   отдельные чаты.
6. `06-spaces.png` — группы и каналы, роли и серверная truth-state подпись.
7. `07-create-group.png` — форма создания группы.
