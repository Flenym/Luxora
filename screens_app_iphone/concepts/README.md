# iPhone concept gallery

These PNGs are captured from the separate `LuxoraDesignLab` app (`app.luxora.designlab`). A purple banner inside every screen identifies whether the shared screen is implemented or is concept-only. Design Lab uses deterministic fixtures and never talks to the server.

The gallery covers authentication, chat navigation, text conversation, future rich messaging, calls, people/search, profile/settings, the invisible-logo loading motion, and the core component states. See the parent [`manifest.json`](../manifest.json) before treating any control as available.
