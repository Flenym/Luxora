# Luxora Operator Console

Локальная операторская панель Luxora Beta-0.1 (только iPhone-этап, серверный бэкенд).

- Владелец и разработчик: **Flenym**
- Версия: **Beta-0.1**

## Что это

Read-only панель для loopback-сервера: состояние, пользователи (пагинация),
чаты (пагинация). Изменение, удаление и блокировки пользователей не входят в
Beta-0.1 и намеренно отсутствуют — поверхность не должна становиться оружием.

## Запуск

```bash
npm install
npm run dev
```

Открой `http://127.0.0.1:4174`, введи адрес API (по умолчанию
`http://127.0.0.1:2222` для `start.bat`) и токен администратора.

## Токен

Сервер отдаёт `/v1/admin/*` только при заданном `ADMIN_TOKEN` (минимум 32
символа), иначе — `503`. Токен хранится только в `sessionStorage` вкладки и
никогда не покидает пару «консоль ↔ твой сервер».
